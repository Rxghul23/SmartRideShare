Abstract
Rapid urbanisation and the growth of corporate campuses have intensified traffic congestion, fuel consumption, and carbon emi ssions, 
largely driven by single -occupancy commuting. This project proposes an AI -Powered Smart RideShare Recommendation and Analytics 
System that goes beyond simple ride booking by applying data analytics and machine learning to historical travel behaviour, p referred 
timings, routes, and employee preferences. The system follows an eleven -stage pipeline — from registration and ride request/offer 
through data cleaning, feature engineering, and a scikit -learn based matching algorithm — to recommend compatible ride partners,
ranked by a computed compatibility score. A layered architecture separates the web application, Ride/Analytics/Admin modules, the AI 
Recommendation Engine, and a central MySQL data store, enabling components to evolve independently. Beyond matching, an analy tics 
dashboard surfaces ridership trends, cost savings, and estimated emission reductions for employees and administrators alike, while a 
continuous feedback loop retrains the matching and demand -prediction models over time. Piloted as a zeroth -review prototype, the
platform is designed to reduce commuting costs, ease peak -hour congestion, and support organisational sustainability goals, with a clear 
roadmap toward GPS-based live tracking, mobile apps, and deep learning -based recommendation.

Introduction
Background &
Motivation
• Traditional carpooling is managed manually via 
spreadsheets and messaging groups — it does not scale 
and rarely adapts to changing schedules.
• An automated, data-driven system continuously learns 
from ride history and feedback to improve match quality 
over time.
• Dashboards built on ride data give administrators visibility 
into utilisation and demand that manual processes cannot 
provide.
Scope of the Project
• A web-based platform where employees register, log in, and request 
or offer a ride.
• Travel data is collected, cleaned, and engineered into features for a 
machine-learning matching engine.
• An analytics module generates reports and dashboards; an admin 
module manages the platform.
• Scoped as a zeroth-review prototype, with a roadmap toward GPS 
tracking and a mobile app.

Module Description
1 Ride Module Core ride lifecycle — create requests/offers, view matches, confirm a shared ride, and track status.
2 Analytics Module Aggregates ride data into occupancy rate, cost savings, distance shared, and emission reduction metrics.
3 Admin Module Manage accounts, monitor usage, configure matching parameters, and export reports.
4 AI Recommendation Engine Scikit-learn model scores/ranks matches; analytics component forecasts demand trends.
5 Data Layer (MySQL) Single source of truth for profiles, ride requests/offers, match history, feedback, and analytics.

Conclusion
The AI-Powered Smart RideShare Recommendation and Analytics System addresses inefficient, high -emission single-
occupancy commuting by applying data analytics and machine learning to automate and optimise ride -sharing. A 
structured pipeline — registration, data collection, feature engineering, AI -based matching, and continuous feedback -
driven improvement — delivers accurate ride recommendations, while the layered architecture keeps the platform 
maintainable and extensible for future enhancements such as live GPS tracking, mobile apps, and deep learning -based 
recommendation. Overall, the project is expected to reduce commuting costs, ease traffic congestion, and support the 
organisation's sustainability objectives.
